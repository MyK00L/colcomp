# Colorful Components: MOP

Exact branch and price algorithm for the colorful components problem.

## Compiling

Compile with `make`, you will need a c++ compiler and HiGHS installed on your system.

## Usage

`./main.out [graph_file] [mode] (options)`

For more information on possible modes and options,
run the executable without any arguments.

Use `./main.out [graph_file] bnp` for the fastest solution.
